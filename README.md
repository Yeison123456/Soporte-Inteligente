<h1>Support AI Backend — FastAPI + MySQL + IA</h1>

<p>
Sistema backend para la gestión de tickets de soporte con clasificación inteligente, predicción de riesgo de churn y asignación automática usando modelos de IA.
Construido con <strong>FastAPI</strong>, <strong>SQLAlchemy Async</strong>, <strong>MySQL</strong> y modelos de IA.
</p>

<hr>

<h2> Tecnologías principales</h2>
<ul>
    <li>Python 3.13</li>
    <li>FastAPI</li>
    <li>SQLAlchemy 2 (Async)</li>
    <li>MySQL 8</li>
    <li>Uvicorn</li>
    <li>Pydantic</li>
    <li>Modelos IA (Clasificación + Churn)</li>
</ul>

<h2> Funcionalidades principales</h2>
    <ul>
        <li>Crear tickets</li>
        <li>Listar todos los tickets</li>
        <li>Validación de cliente</li>
        <li>Asignación de account manager</li>
        <li>Historial del estado</li>
        <li>Clasificación IA</li>
        <li>Cálculo de churn</li>
        <li>Autenticación con roles</li>
    </ul>

<h2> IA incluida</h2>
    <h3> Clasificación de ticket</h3>
    <p>Correctivo / Evolutivo</p>
    <h3> Predictor de CHURN</h3>
    <p>Devuelve un score entre 0 y 100.</p>
